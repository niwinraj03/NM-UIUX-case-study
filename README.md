🌐 App Design Collection – Figma UI Projects

Description:
This repository showcases a collection of three modern mobile app UI/UX designs built using Figma — covering travel, healthcare, and music streaming experiences. Each project demonstrates unique design principles, color palettes, and interactive prototypes focused on delivering a clean and user-friendly interface.

📱 Included Projects:

1. 🎵 TuneBox – Music Streaming App
A sleek and engaging app design for discovering, streaming, and organizing music. Features artist profiles, playlists, and an immersive player screen.
🔗 https://www.figma.com/design/JgrBFKe2jaGgHfEGq9aMim?node-id=0-1


2. 🌍 TravelEase – Traveler App
A travel planning and booking interface helping users explore destinations, create itineraries, and manage trips with ease.
🔗 https://www.figma.com/design/ZdeBR8e5bkphb0ysZbkeMU?node-id=1-4007


3. 🏥 MediCare – Health Care App
A health management app design enabling users to book appointments, monitor health stats, and access medical records.
🔗 https://www.figma.com/design/zG8K1Vju7hyFg4hYChLF1R?node-id=1-4007
